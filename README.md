# 📘 Smart Productivity Tracker  

A **full-stack productivity management platform** that helps users **track tasks, manage history, make better decisions, play a quick game to refresh, and stay connected.**  

Built with the **MERN stack (MongoDB, Express.js, React, Node.js)** + modern libraries, it provides a **clean and intuitive UI** designed for productivity.  

👉 **Live Demo**: [Smart Productivity Tracker (Vercel Deploy)](https://smart-productivity-tracker-blush.vercel.app/)  

---

## 🚀 Features Overview  

### 🏠 Dashboard  
- Central hub with **quick insights** into user activity.  
- Displays **task stats, recent actions, and shortcuts**.  
- Designed as the **first page after login**.  

### ✅ Tasks  
- Add, edit, complete, and delete tasks.  
- Each action is logged into **History**.  
- Dynamic updates with persistent storage.  

### 🌟 Decision Helper  
- AI-powered suggestion system.  
- Provides **guided recommendations** for smarter decisions.  

### 📜 History  
- Shows a **timeline of completed tasks & actions**.  
- Helps track productivity progress.  

### 👤 Profile  
- Secure login/signup.  
- Personalized profile with user-specific details.  

### 🎮 Snake Game  
- Built-in **Snake Game** with sound effects & scoring.  
- Quick breaks to stay refreshed.  

### ✉️ Contact  
- Contact form auto-fills user **name & email**.  
- Messages sent securely to admin.  
- For feedback, support, or requests.  

---

## 📌 How to Use  

1. **Sign up / Log in** securely.  
2. Open the **Dashboard** for a quick overview.  
3. Manage tasks in **Tasks** → track them in **History**.  
4. Use **Decision Helper** when you need guidance.  
5. Check activity timeline in **History**.  
6. View personal details in **Profile**.  
7. Play the **Snake Game 🎮** to refresh.  
8. Reach out via the **Contact Page**.
